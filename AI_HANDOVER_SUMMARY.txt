1. PROJECT MISSION & CLIENT REQUIREMENTS
--------------------------------------------------------------------------------
The user requested a complete overhaul of the FluxECS website (Department of
Electronics & Computer Science council at VESIT, Mumbai). Previous redesigns
were rejected for introducing fake race cars, circuit track maps, fake telemetry
status bars, robot graphics, and excessive clutter.

Core Goals:
- True Minimal, Premium Engineering Council Aesthetic:
  Carbon & Crimson color palette (#0D1014, #1B2026, #30363E, #D94A5B, #9EA6AF, #EFF0F2).
  Inspiration drawn from e-Yantra (IIT Bombay) and previous TLC web projects.
- Authentic Poster-First Events Platform:
  Poster artwork displayed in genuine 3:4 aspect ratio cards with upcoming/past
  tabs, zoomable high-resolution lightbox, and dynamic event routes (/events/[slug]).
- Full-Fledged Admin Management Portal (/admin):
  Password-authenticated dashboard where council admins can create, view, edit all
  fields, upload poster files directly, toggle draft/publish, and delete events.
- Audio & Motorsport Precision:
  Real full-length soundtrack sourced directly from user's Music folder:
  "Don Toliver - Lose My Mind (feat. Doja Cat) [From F1® The Movie]" (3:30 min).
  Persistent floating global player widget (PitRadio) visible on all pages with
  prominent radio icon, ON/OFF status badge, and jumping equalizer bars.
- High-Performance Motion:
  GSAP and Anime.js used for kinetic typography line mask reveals, staggered
  entrances, and interactive mouse parallax tilt without tacky gimmicks.
- ABSOLUTE PROHIBITION ON "AI SLOP":
  Strict removal of fake sector tags (S1 HARDWARE BENCH, S2 COMPETITIVE ALGORITHMS,
  S3 PEER COMMUNITY), fake track status badges (TRACK STATUS: GREEN // PIT OPEN),
  and coordinates (19.0458° N, 72.8889° E). No em dashes (— or –) in copy.

3. ARCHITECTURE & KEY FILE OVERVIEW
--------------------------------------------------------------------------------
- app/layout.js:
  Root Server Component. Injects fonts (Barlow, Saira), metadata, Skip link,
  Navbar, main content, Footer, and globally mounts <PitRadio />.

- components/ui/PitRadio.tsx:
  Global floating team radio player (fixed bottom-5 right-5 z-50).
  Plays /media/f1-soundtrack.mp3 (Don Toliver - Lose My Mind [F1 Movie]).
  Features antenna SVG icon, ON/OFF toggle, live EQ spectrum bars, track info,
  and syncs with hero via window events ('flux:toggle-radio', 'flux:radio-change', 'flux:query-radio').

- components/home/racing-hero.tsx:
  Hero section with <KineticGrid /> at opacity 0.20 (!bg-transparent).
  GSAP kinetic typography animation reveals lines of "FROM CIRCUITS TO CODE." via
  overflow-hidden line masks. Interactive GSAP mouse tilt parallax on header.
  Zero AI slop badges. Synced audio button in toolbar.

- components/home/identity-hero.module.css:
  CSS module for hero section. Strict Carbon & Crimson styling. Cleaned of all
  telemetryRow, pulseBeacon, and sectorStrip classes.

- app/page.js:
  Minimal homepage:
  1. RacingHero (Kinetic grid, GSAP typography reveal, synced pit radio trigger)
  2. Featured Event (Algorithm's Auction 2.0 with authentic 3:4 poster & active registration)
  3. Inside the Lab Photo Band (IoTA authentic engineering photo)
  ("The council" section removed per user request).
  4. Footer

- app/events/page.js & components/EventsView.js:
  Minimal poster-first events catalog inspired by e-Yantra and TLC web.
  Tabs for Upcoming and Past events. 3:4 aspect ratio cards. Lightbox zoom.

- app/events/[slug]/page.js & components/EventDetailClient.js:
  Dynamic event page displaying high-res poster, date, time, venue, description,
  rules list, syllabus/curriculum, eligibility, schedule breakdown, and Google Form registration.

- app/admin/page.js:
  Admin portal protected by password authentication (token cookie flux_admin_token).
  Password configured in .env.local as ADMIN_PASSWORD (default: REMOVED_SHARED_CREDENTIAL).
  Renders AdminEventManager and recent inquiries.

- components/AdminEventManager.js:
  Comprehensive event editor. Supports direct poster file upload (/api/admin/upload),
  live 3:4 artwork preview, editing all fields in-place, publish/draft toggle, and delete.

- app/about/page.js:
  Redesigned About page matching Carbon & Crimson palette. Features core domains,
  faculty coordinators, senior/junior council rosters, and IoTA lab location.

- lib/events-store.js:
  Dual-storage manager: MongoDB Atlas if MONGODB_URI is provided, with seamless
  fallback to data/events-store.json for local development without external credentials.
  Normalizes rules, eligibility, syllabus, and dates.

- app/api/events/route.js & app/api/events/[slug]/route.js:
  REST API endpoints: GET (public sees only published events; admin sees drafts with ?all=true),
  POST (create event), PATCH (update/publish toggle), DELETE (remove event).

- app/api/admin/upload/route.js:
  Multipart file upload endpoint saving to public/posters/uploads/ with size/type validation.

- scripts/verify-v2.mjs:
  Automated 26-test verification suite covering auth, routing, draft protection,
  poster upload, event creation, live update, and deletion.
