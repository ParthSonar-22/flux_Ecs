## Risks and remedy
- Shared static HMAC admin cookie: no individual identity, session revocation or roles. Replace with Payload's mature multi-user authentication and server permissions.
- Writes to public/ and JSON files are not durable on serverless hosting. Adopt one SQLite/libSQL content store (local persistent file; managed Turso in production), private S3-compatible media storage, configured email.
- Failed Mongo writes silently fall back to JSON; missing documents can reappear. Remove competing runtime store after idempotent content migration.
- Uploads trust MIME/extension and permit raw SVG. Validate signatures and dimensions, keep draft files private, enable only explicitly licensed media.
- Commercial audio was publicly tracked. Preserve private local reference under ignored scratch, remove public copies and redact shared password. No copyrighted files or secret-bearing history may be pushed.
- Contact/newsletter require absent Mongo credentials; no real delivery verified. Migrate into CMS inbox, honest submission result and notification status.
- No hosted service credentials found. Connected Vercel account has no project matching Flux. Never claim hosted persistence or email delivery is tested before configuration.
