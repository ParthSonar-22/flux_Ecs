## FluxECS V2: Visual Design and Content Refinement

Continue implementing FluxECS V2, but treat the following design instructions as mandatory across the entire website.

### 1. Minimalism and Visual Quality

The website must look like it was designed by an experienced professional design team, not generated using AI.

Our inspiration is premium motorsport websites, SpaceX's cinematic presentation and modern editorial design.

Follow these principles:

- Less content, more visual impact.
- Generous whitespace and carefully controlled spacing.
- Strong typography and clear visual hierarchy.
- Large, meaningful photography and video.
- Minimal text with deliberate placement.
- Clean compositions with room for elements to breathe.
- Consistent alignment, margins, proportions and spacing.
- Restrained use of color, borders and visual effects.
- Original layouts that feel intentional rather than template-generated.

Do not fill empty areas simply because space is available. Whitespace is a design element.

### 2. Avoid Generic AI Website Design

Strictly avoid:

- Generic SaaS landing page layouts.
- Endless rounded cards and repetitive bento grids.
- Excessive gradients, glowing borders and glassmorphism.
- Random floating elements, decorative particles and unnecessary background patterns.
- Oversized marketing slogans on every section.
- Repeated statistics, badges and feature descriptions.
- Generic headings such as "Unleashing Innovation", "Empowering Tomorrow" or "Where Ideas Meet Possibilities".
- Fake statistics, invented testimonials and placeholder achievements.
- Excessive emojis, unnecessary icons and decorative labels.
- Overly enthusiastic or robotic copywriting.
- Em dashes in all visible website content.

Do not use a three-column card layout for every section. Each section should have a distinct but consistent visual composition.

### 3. Content Direction

FluxECS is the official Electronics and Computer Science council at VESIT.

The website must communicate real information clearly and concisely.

Keep homepage copy extremely minimal.

Example:

**FLUXECS**

Electronics & Computer Science  
VESIT, Mumbai

**ENGINEERED TO GO FURTHER.**

Explore Events | Our Projects

Use short, natural descriptions throughout the website. Avoid filler paragraphs and exaggerated claims.

Preserve real council details, events, photographs, posters, projects and achievements from the existing website.

Do not invent content to make a layout look complete. If content is unavailable, design the layout to work without it.

### 4. Motorsport Visual Identity

The F1-inspired theme must feel premium, cinematic and technical, not like a racing game or fan website.

Use:

- Carbon black and graphite.
- Off-white typography.
- Restrained velocity-orange accents.
- Subtle telemetry-inspired visual language.
- Editorial racing photography.
- Strong condensed headlines where appropriate.
- Precise lines, technical labels and subtle racing references.

Do not add racing flags, speedometers, circuits or HUD decorations everywhere.

The motorsport theme should complement the council's identity, not overshadow its actual purpose.

### 5. Animation Philosophy

Animations must be smooth, restrained and purposeful.

Use:

- GSAP for cinematic scroll sequences.
- Anime.js for custom HUD, SVG and technical interactions.
- Motion for React micro-interactions.
- Three.js and React Three Fiber for the interactive racing car.
- 21st.dev for carefully selected, reusable UI components.

Each animation must contribute to storytelling, interaction or visual hierarchy.

Avoid animations simply because the technology supports them.

Do not let multiple animation libraries control the same element or property simultaneously.

Respect reduced-motion preferences and prioritize mobile performance.

### 6. Page Design

Maintain the same design language across Home, Events, Projects, Gallery, Stories, Council, About and Contact.

Each page must have:

- A distinctive but restrained hero.
- Clear page hierarchy.
- Minimal, useful content.
- Appropriate photography.
- Consistent typography.
- Plenty of whitespace.
- Smooth but subtle transitions.
- Excellent responsive layouts.

Keep the admin dashboard clean, efficient and functional. It does not need cinematic animations.

### 7. Implementation and Review

Do not rebuild the website using generic templates.

Use existing components only when they fit our design system. Customize 21st.dev components rather than copying their default styling.

Before finishing each major section, inspect it visually in a real browser.

Check:

- Desktop composition.
- Mobile layout.
- Typography and readability.
- Empty space and visual balance.
- Image quality.
- Animation smoothness.
- Accessibility.
- Performance.
- Consistency with the rest of the website.

Remove unnecessary elements during review.

If a section looks cluttered, simplify it rather than adding more decoration.

### Final Design Standard

FluxECS should look like an independent, professionally designed engineering council website with the cinematic confidence of a motorsport brand.

It should feel precise, energetic, modern and memorable.

**The website should impress through restraint, composition, photography, typography and execution, not through the number of effects or components used.**

Continue implementation in the existing development branch. Preserve working functionality. Do not push or deploy without approval.
